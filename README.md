# Netflix Data Analysis & Visualization

A data analysis and visualization project using Python, Pandas, and Matplotlib.

## 📌 Project Overview

This project analyzes a Netflix-style dataset to understand patterns in movies and TV shows, including release years, countries, content ratings, and movie durations.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Dataset

## 📊 Visualizations

The project includes the following visualizations:

1. Top 10 Countries by Number of Shows
2. Movie Duration Distribution
3. Movies Released Per Year
4. TV Shows Released Per Year
5. Content Rating Analysis
6. Movies vs TV Shows Comparison

## 📁 Project Files

- `main.py` — Python analysis and visualization code
- `netflix_style_movies_2000_FIXED.csv` — Dataset
- `.png` files — Generated visualizations
